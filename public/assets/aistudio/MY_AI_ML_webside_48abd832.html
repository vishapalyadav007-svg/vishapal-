Learn AI / ML

Core ideas, explained simply

AI and ML are large fields. Start by understanding what each term means, how data is used, and where these technologies appear in everyday life.

AI

Artificial Intelligence

AI is a broad field that creates systems able to perform tasks associated with human intelligence, such as recognizing speech or recommending a video.

ML

Machine Learning

ML is a part of AI where a computer finds patterns from examples and data instead of relying only on rules written by a programmer.

DL

Deep Learning

Deep Learning is a type of ML that uses multi-layer neural networks, often for image, audio and language data.

DS

Data Science

Data Science combines collection, cleaning, analysis and communication to help people make better decisions from information.

{ }

Dataset

A dataset is an organized collection of data. A table of study hours and marks is a simple example.

S

Supervised Learning

Training data has answers or labels. Emails labelled “spam” or “not spam” can teach a classifier.

U

Unsupervised Learning

Data has no provided answers. The system may find natural groups, such as similar customer behaviours.

↗

Predictions

After training, a model applies learned patterns to new input. Predictions should be tested and checked for errors.

AI career guide

Explore roles without rushing the choice

These roles overlap in real workplaces. Build foundations, try small projects, and find out what work you enjoy. This guide does not guarantee a salary, job or placement.

Builds ML systems

Machine Learning Engineer

Creates, tests and maintains ML models that can be used inside products or services.

  • Skills: Python, ML, data handling, software basics.
  • Order: Python → data → ML → deployment basics.
  • First project: Spam-message classifier.
Applies AI features

AI Engineer

Uses AI methods and software engineering to build useful, responsible application features.

  • Skills: Python, APIs, prompt design, testing.
  • Order: Programming → AI concepts → application building.
  • First project: Rule-based FAQ helper.
Finds data insights

Data Analyst

Explores data, creates reports and visualizations, and explains what the evidence suggests.

  • Skills: Spreadsheets, SQL, charts, communication.
  • Order: Spreadsheets → statistics → SQL → dashboards.
  • First project: Student-score data dashboard.
Studies data deeply

Data Scientist

Uses statistics, programming and ML to investigate questions and create data-driven models.

  • Skills: Python, statistics, ML, storytelling.
  • Order: Data analysis → statistics → ML → experiments.
  • First project: Sales trend analysis.
Neural networks

Deep Learning Engineer

Develops and evaluates neural-network solutions for complex image, text, audio or other data.

  • Skills: Python, linear algebra, ML, neural networks.
  • Order: Python → math → ML → deep learning.
  • First project: Handwritten digit recognizer.
